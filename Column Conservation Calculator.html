Column Conservation Calculator

Type the residues found in one column of an alignment and choose a threshold in bits. The calculator scores the column with the information content formula used by the NCBI Multiple Sequence Alignment Viewer and colors it red (highly conserved) or blue (less conserved).

One-letter amino acid codes, one letter per sequence, up to 20. A dash (-) marks a gap.

    The arithmetic

    ResidueCountfqf × log₂(f / q)
    I = Σ f(i) · log₂( f(i) / q(i) )
    • f is the fraction of the sequences that carry the residue. q is how often that residue turns up in proteins at random (the BLOSUM62 background frequency).
    • Red or blue. NCBI colors a column red when its score is at or above the threshold, and blue when it is below. The colors belong to the whole column. A single odd residue does not get its own color.
    • Identity is the strictest NCBI setting. The column is red only when every sequence has the same residue, whatever the score.
    • Gaps. NCBI only colors columns that contain no gaps, so a column with a dash is left uncolored here.
    • Try this. Load "19 Gly + 1 Trp" and then "Gly + 1 Trp" with 4 sequences. The score barely moves, so adding sequences does not push a column across a threshold.

    The q values are rounded BLOSUM62 background frequencies, so a score may differ from NCBI's in the second decimal place. The threshold options (one to five bits, and identity) come from the NCBI MSA Viewer embedding API documentation. Whether a score exactly equal to the threshold counts as red is assumed here.
